Hi, I'm phinguin. I build stuff, run it on real servers, and then try to break it.

Mostly into security and backend/infra — the kind of work where you have to know what's actually happening under the framework. Most of what's on here comes from projects people actually use:

- An academy platform. Teachers use it every week for homework submission, grading and weekly student reports. Flask, React and MySQL, in Docker on AWS. Designed the schema, run it in production, and pen-tested its own file upload/download endpoints.
- An online judge for IB CS practice problems. Built on QingdaoU OnlineJudge and rebuilt to run natively on arm64, on two Oracle Cloud ARM servers with separate dev, staging and prod.
- Home automation. An ESP32-C3 driving a servo that presses my range hood's button when the air in my place gets bad.
- Low-level stuff. A small ptrace debugger in C, and notes on Linux kernel bugs.

I use AI tools a lot when I work, and a bunch of these posts are about where they were wrong and how I checked.
