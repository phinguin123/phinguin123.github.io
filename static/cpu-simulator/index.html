Beyond One Instruction: Memory Hierarchy, Multi-Core & Pipelining

Explore how modern processors overcome the Von Neumann bottleneck using inclusive LRU caches, parallel cores, and instruction pipelines.

Activity 1

Memory Hierarchy — Follow a Read (Fully Associative Inclusive Cache with LRU)

Checking starts at L1 (+1 cost) → L2 (+3 cost) → L3 (+8 cost) → RAM (+25 cost) only on a MISS. A HIT supplies the value immediately, moves the entry to the MRU (Most Recently Used) front of each checked cache, and copies it into any cache level that missed. Inclusive eviction rule: When a larger cache evicts its LRU entry, any copy in smaller caches is removed too.

CPU Registers & SRAM Cache Fastest, smallest storage built directly inside the CPU die. Volatile; holds immediate operands and recently accessed lines.
Main Memory (DRAM) Holds active programs and data currently running. Volatile (clears on power off), much larger capacity, higher latency (+25).

Where a GPU Fits (SIMT / Massive Data Parallelism)

While a CPU has a handful of complex cores optimized for sequential branching and low latency, a GPU contains hundreds or thousands of simpler ALUs executing the same instruction across many data elements simultaneously. Because squaring 2, 3, 4, 5, 6, 7 has zero data dependencies between elements, a GPU dispatches all 6 elements in parallel and finishes the entire batch in just 2 steps!

Instruction Set Architecture (ISA) Reference

This simulator uses the classic Little Man Computer (LMC) / Von Neumann assembly language. Labels (such as LOOP or ONE DAT 1) and explicit address prefixes (like 6: DAT 25) are supported.

Mnemonic Name RTL / Micro-Operation Description
INP Input AC ← InputQueue Reads next number from the Input Stream into Accumulator (AC).
OUT Output Output ← [AC] Emits the current value of AC to the Output Tape.
LDA x Load into AC MAR ← x; MDR ← RAM[x]; AC ← [MDR] Loads the value stored at RAM address x into AC.
STA x Store from AC MAR ← x; MDR ← [AC]; RAM[x] ← [MDR] Writes the value in AC into RAM address x.
ADD x Add MAR ← x; MDR ← RAM[x]; AC ← [AC] + [MDR] Adds the value at RAM address x to AC.
SUB x Subtract MAR ← x; MDR ← RAM[x]; AC ← [AC] - [MDR] Subtracts the value at RAM address x from AC.
BRA x Branch Always PC ← x Unconditionally sets PC to address x.
BRZ x Branch if Zero if (AC == 0) PC ← x Branches to address x if AC is equal to 0.
BRP x Branch if Zero/Positive if (AC ≥ 0) PC ← x Branches to address x if AC is zero or positive.
HLT Halt STATE ← HALTED Stops instruction execution.
DAT v Data Location RAM[here] = v Reserves a RAM address initialized to integer v (default 0).
